# Daniel Garriga Photography

One-page website for Daniel Garriga Photography: hospitality and commercial real estate photography in New York.

- `index.html`: the whole site (HTML, CSS and a little JavaScript, no build step)
- `assets/images/`: photography
- `assets/logos/`: client logos (black, transparent PNG)

To publish with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
